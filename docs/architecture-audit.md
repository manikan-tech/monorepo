# تدقيق معماري (Architecture Audit)

| السؤال | الحالة | الدليل من الكود (اقتباس + مسار الملف) |
|---|---|---|
| 1. الخدمة (`recommendation-service`) مستقلة تمامًا (Microservice) — مفيش استيراد مباشر من كود خدمات تانية؟ | ✅ نعم | جميع الاستيرادات في الخدمة داخلية فقط. لا يوجد أي `import` أو `sys.path.append` لخدمات أخرى. مثال من `app/agent.py` السطر 13-16: <br> `from .config import get_settings`<br>`from .schemas import ActionType, RecommendationOutput, MeasurementInput`<br>`from .Bedrock import _call_bedrock_gateway`<br>`from .retrieval import retrieve_relevant_products, format_retrieved_context` |
| 2. مفيش اتصال مباشر بقاعدة البيانات من داخل `recommendation-service`؟ | ✅ نعم | لا يوجد استيراد لمكتبات `Prisma`, `SQLAlchemy`, أو `Postgres` داخل الكود. يتم استلام البيانات جاهزة من الـ Proxy. مكتبة `asyncpg` موجودة فقط في `requirements.txt` كاعتمادية غير مستخدمة داخل `app/`. |
| 3. الـ widget بيتواصل حصريًا عبر `/api/widget/recommend` (Next.js Proxy)، مفيش أي `fetch` مباشر لبورت الـ FastAPI من كود المتصفح؟ | ✅ نعم | في ملف `apps/store/public/recommend-widget.js` السطر 287:<br> `const response = await fetch(\`\${STORE_API_BASE}/api/widget/recommend\`, {...` |
| 4. الـ Proxy بيتحقق من: مفتاح الـ widget (`X-Manikan-Key`)، الـ Origin allowlist، الاشتراك النشط (`Subscription`)، قبل ما يوصّل للـ backend؟ | ✅ نعم | في ملف `apps/store/app/api/widget/recommend/route.ts` السطر 30:<br> `const auth = await authorizeWidgetRequest(request, CORS_HEADERS, "RECOMMENDATION");`<br>والتي تنفذ كافة التحققات في `apps/store/app/lib/widget-auth.ts`. |
| 5. الاتصال الداخلي (Next.js → FastAPI) محمي بمفتاح منفصل (`X-Manikan-Internal-Key`) غير مكشوف للمتصفح؟ | ✅ نعم | في ملف `apps/store/app/api/widget/recommend/route.ts` السطر 97-102:<br> `const upstream = await fetch(\`\${RECOMMENDATION_SERVICE_URL}/recommend\`, {`<br>`headers: {`<br>`"Content-Type": "application/json",`<br>`"X-Manikan-Internal-Key": RECOMMENDATION_SERVICE_KEY,`<br>`},` |
| 6. هل التصميم فعليًا "Portable" — أي Retailer جديد يقدر يركّب الـ widget بـ `<script>` tag + مفتاحه الخاص بدون تعديل كود؟ | ✅ نعم | المفتاح يمرر عبر `X-Manikan-Key`. وفي `apps/store/prisma/seed.ts` السطر 171-175، يتم توليد المفتاح الخاص بالـ Retailer وحفظه في `ServiceApiKey`: <br>`await prisma.serviceApiKey.upsert({`<br>`where: { retailerId_service: { retailerId: retailer.id, service: "RECOMMENDATION" } },`<br>`update: { apiKey: "pk_live_632dba109f17b0a768f77addefa42f81a86c9f3653a3b40c" },`<br>`create: { retailerId: retailer.id, service: "RECOMMENDATION", apiKey: "pk_live_632dba109f17b0a768f77addefa42f81a86c9f3653a3b40c" },`<br>`});` |
